BAGIAN 1: SARAN ARSITEKTUR & STRATEGI LARAVEL (BEST PRACTICES)

Menggunakan Laravel 11 untuk proyek senilai Rp2.300.000 dengan target pengerjaan 8 hari kerja adalah pilihan yang sangat tepat, cepat, dan menguntungkan, terutama karena mudah di-deploy di Shared/Cloud Hosting cPanel Indonesia (Hostinger, Niagahoster, Rumahweb, DomaiNesia, IDCloudHost) tanpa perlu biaya sewa VPS bulanan yang mahal.

Berikut adalah 5 Saran Teknis Terbaik untuk pengerjaan proyek ini:

1. Gunakan FilamentPHP v3 untuk CMS Login Admin (/admin)

Kenapa? Jangan membuat halaman CRUD Admin dari nol secara manual. Dengan FilamentPHP v3, Anda bisa membuat halaman Login Admin, Dashboard Statistik, CRUD Paket Wisata, Upload Foto Galeri, dan Editor Artikel yang sangat modern hanya dalam waktu 2–3 jam.

Fitur Unggulan untuk Travel: Filament memiliki komponen Repeater bawaan yang sangat cocok untuk membuat form input Jadwal Harian (Itinerary Hari 1, Hari 2, dst.) serta TagsInput untuk fasilitas Include/Exclude yang disimpan otomatis sebagai kolom JSON di MySQL.

2. Gunakan Laravel Blade + Tailwind CSS + Alpine.js untuk Halaman Publik (Multi-Page)

Kenapa? Sesuai kesepakatan terbaru bahwa website bukan single-page, melainkan Multi-Page Dinamis (bisa berpindah halaman), penggunaan Laravel Blade sangat cepat dimuat dan 100% ramah SEO Google.

Gunakan Alpine.js (sangat ringan) untuk interaktivitas di dalam halaman seperti:

Modal Pop-up Itinerary (saat tombol "Lihat Rundown" diklik).

Lightbox Gallery (memperbesar foto kegiatan ke layar penuh).

Accordion FAQ & Hamburger Menu Mobile.

3. Simpan Itinerary & Fasilitas dalam Kolom JSON di Database MySQL

Daripada membuat terlalu banyak tabel relasi yang rumit, pada tabel tour_packages, gunakan tipe data json untuk kolom itineraries, includes, dan excludes. Di Model TourPackage.php cukup tambahkan:

protected $casts = [
    'itineraries' => 'array',
    'includes' => 'array',
    'excludes' => 'array',
    'is_featured' => 'boolean',
    'is_active' => 'boolean',
];


4. Siapkan Tabel custom_pages untuk Fitur Tambahan yang Menyusul (Pasal 8 & Pasal 10)

Karena pihak Nirwana Tour memiliki klausul fleksibel untuk menambahkan halaman/fitur baru yang saat ini belum ditentukan isinya, buatlah 1 tabel dinamis bernama custom_pages (title, slug, content, show_in_navbar, is_active).

Saat klien meminta halaman baru di kemudian hari (misal: "Syarat & Ketentuan Sewa Bus" atau "Info Kunjungan Industri"), Anda atau admin cukup menambahkannya lewat CMS tanpa perlu mengubah kode program.

5. Catatan Penting: Tanpa Fitur Kalkulator

Sesuai kesepakatan kontrak final, tidak ada fitur Kalkulator Estimasi Biaya. Seluruh tombol aksi (CTA) pada kartu paket wisata dan halaman detail langsung mengarah ke WhatsApp Admin dengan format pesan otomatis (pre-filled message) yang mencantumkan nama paket yang dipilih pengunjung.

BAGIAN 3: SKEMA DATABASE MYSQL (LARAVEL MIGRATIONS)

Berikut adalah rancangan 9 tabel database (migrations) untuk sistem ini:

users (Login Admin CMS)

id, name, email, password, timestamps.

tour_packages (Katalog Paket Wisata)

id, title, slug (unique), category (lampung, nusantara, edukasi, armada), duration (string, contoh: 3 Hari 2 Malam), price (unsignedBigInteger), price_unit (string, default: / Orang), thumbnail (string), description (text), includes (json), excludes (json), itineraries (json), is_featured (boolean), is_active (boolean), timestamps.

services (4 Layanan Utama)

id, title, slug, icon (string), short_description (text), full_description (longText), whatsapp_text (string), sort_order (integer), is_active (boolean), timestamps.

galleries (Galeri Dokumentasi & Lightbox)

id, title, client_name (string, contoh: PT Bukit Asam / SMAN 2), category (string), image_path (string), trip_date (date, nullable), caption (text, nullable), is_active (boolean), timestamps.

partners (Mitra BUMN, Instansi & Sekolah)

id, name, logo_path (string, nullable), category (BUMN, Instansi, Sekolah, Universitas), sort_order (integer), is_active (boolean), timestamps.

posts (Artikel & Promo)

id, title, slug (unique), thumbnail (string), excerpt (text), content (longText), is_published (boolean), published_at (timestamp, nullable), timestamps.

faqs (Tanya Jawab)

id, question (string), answer (text), sort_order (integer), is_active (boolean), timestamps.

custom_pages (Slot Fitur/Halaman Tambahan Menyusul)

id, title, slug (unique), content (longText), meta_description (string, nullable), show_in_navbar (boolean, default: false), is_active (boolean, default: true), timestamps.

site_settings (Pengaturan Profil, Sambutan Pimpinan, & Nomor WA)

id, company_name, tagline, owner_name (Kiki M Alfin), owner_title (Pimpinan & Founder), owner_photo, owner_greeting (text), whatsapp_number, email, address, google_maps_embed (text), instagram_url, facebook_url, years_experience, total_trips, satisfaction_rate, timestamps.

BAGIAN 5: PANDUAN LANGKAH KERJA CEPAT (8 HARI KERJA)

Agar pengerjaan selesai tepat waktu sesuai Pasal 6 Kontrak (8 Hari Kerja), ikuti urutan perintah Terminal berikut di komputer Anda:

# 1. Buat project Laravel 11 baru
composer create-project laravel/laravel nirwana-tour
cd nirwana-tour

# 2. Konfigurasi database di file .env (DB_DATABASE=nirwana_tour) lalu jalankan migrasi awal
php artisan migrate

# 3. Install FilamentPHP v3 untuk CMS Login Admin instan
composer require filament/filament:"^3.2" -W
php artisan filament:install --panels

# 4. Buat akun Admin pertama untuk Nirwana Tour
php artisan make:filament-user

# 5. Aktifkan symlink agar foto yang diupload muncul di halaman depan
php artisan storage:link


Setelah instalasi dasar di atas selesai, gunakan Master Prompt pada Bagian 4 untuk men-generate seluruh tabel, data awal (Seeder), halaman Blade multi-page, serta form CRUD Filament. Website akan siap didemokan kepada Bapak Kiki M Alfin dalam waktu singkat!
